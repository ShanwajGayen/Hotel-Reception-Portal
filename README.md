# The Grand Podder Hotel – Reception Desk

A modern, responsive **Hotel Reception & Guest Check-In Management System** built using **HTML, CSS, and JavaScript**.

The project provides a stylish hotel welcome screen and an interactive reception desk where staff can register guests, verify mobile OTPs, manage multiple occupants and government IDs, calculate room billing with GST, capture digital signatures, and generate a printable customer registration slip.

## ✨ Features

* 🏨 Luxury-style hotel welcome screen
* 🕐 Real-time day, date, and clock display
* 👤 Guest registration and verification
* 📱 Demo mobile OTP verification
* 🪪 Government ID verification with demo OTP
* 👥 Add/remove multiple members
* 🛏️ Room and stay details
* 💰 Automatic room cost and GST calculation
* 💳 Advance payment and balance calculation
* ✍️ Digital signature pad
* 🧾 Customer folio / registration slip generation
* 🖨️ Print or save customer copy
* 📱 Responsive design for mobile and desktop
* 🎨 Modern UI with animations and custom styling

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* HTML Canvas API
